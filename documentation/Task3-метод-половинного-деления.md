# Task3 — метод половинного деления

Task3 реализует вариант №3 из списка курса: дана непрерывная функция, отрезок
`[a, b]`, на концах которого функция меняет знак, и точность `epsilon`.
Требуется найти приближённый корень методом половинного деления.

## Алгоритм

На каждой итерации вычисляется середина отрезка:

```text
c = (a + b) / 2
```

Если `f(a)` и `f(c)` имеют разные знаки, новым отрезком становится `[a, c]`.
Иначе выбирается `[c, b]`. Итерации продолжаются, пока половина длины
отрезка больше заданной точности:

```text
(b - a) / 2 > epsilon
```

Ответом считается середина итогового отрезка.

## Формат задания

Генератор содержит 10 шаблонов: линейную, квадратную, кубическую,
тригонометрические, экспоненциальную, логарифмическую и другие монотонные
функции. Параметры и точность рандомизируются при каждом запросе.

Серверный протокол проверяет целочисленный ответ, поэтому вычисленный корень
показывается среди четырёх вариантов. Пользователь отправляет номер `1`–`4`.
Три неверных значения отстоят от вычисленного корня дальше `epsilon`.

## Подключение к проекту

- сервер: команда `task3 <1-10>` вызывает `task3_generate()`;
- статистика: результат записывается в первые 10 ячеек `StatisticTask3`;
- клиент: для Task3 включает четыре радиокнопки и отправляет номер выбранного
  варианта;
- `mystats 3` показывает десять значений статистики Task3.

## Тестирование

`tests/tst_task3_test.cpp` проверяет неверные номера шаблонов, формат всех
десяти шаблонов, математическую точность выбранного ответа на 300 случайных
генерациях и попарную различимость вариантов ещё на 200 генерациях.
