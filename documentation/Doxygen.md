# Документация проекта с помощью Doxygen

Doxygen читает исходные файлы C++ и специальные комментарии `/** ... */`, после чего создаёт связанные HTML-страницы для классов, структур, перечислений и функций проекта.

## Подготовленные файлы

- `Doxyfile` — конфигурация генератора;
- документирующие комментарии в заголовочных файлах сервера, клиента и заданий;
- `documentation/doxygen/html` — готовая HTML-документация;
- `documentation/doxygen-warnings.log` — предупреждения последней генерации.

Папка `wiki` в генерации не участвует и не изменяется.

## Повторная генерация

Открыть PowerShell в корне проекта и выполнить:

```powershell
doxygen Doxyfile
```

Если PowerShell ещё не видит Doxygen после установки, использовать полный путь:

```powershell
& "C:\Program Files\doxygen\bin\doxygen.exe" Doxyfile
```

Главная страница результата:

```text
documentation\doxygen\html\index.html
```

Её можно открыть двойным щелчком или командой:

```powershell
Start-Process .\documentation\doxygen\html\index.html
```

## Что находится в документации

- `MyTcpServer` — приём TCP-подключений и хранение пользовательских сессий;
- `DatabaseManager` — пользователи, роли и статистика в SQLite;
- `UserSession`, `UserInfo`, `UserStats` — структуры данных сервера;
- `MainWindow` — оконный Qt-клиент;
- `Task1Problem`–`Task4Problem` и функции генерации заданий;
- обработчики текстовых команд сервера;
- страницы исходных и заголовочных файлов.

## Graphviz

Graphviz подключён к Doxygen через параметр `HAVE_DOT = YES`. Документация содержит SVG-графы наследования и взаимодействия классов, зависимости заголовочных файлов, иерархию каталогов, а также графы вызываемых и вызывающих функций.

В конфигурации указан путь:

```text
DOT_PATH = "C:/Program Files/Graphviz/bin"
```

Если проект запускается на компьютере, где Graphviz установлен в другом каталоге, значение `DOT_PATH` необходимо изменить или добавить каталог `bin` Graphviz в переменную `PATH`.

## Результат проверки

Документация успешно сгенерирована Doxygen 1.18.0 и Graphviz 16.1.0. Создана главная HTML-страница, страницы классов, структур, функций, исходных файлов и SVG-графов. Итоговый журнал генерации содержит 0 предупреждений.
