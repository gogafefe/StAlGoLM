# Запуск сервера StAlGoLM в Docker

Docker-контейнер собирает и запускает только серверную часть проекта. Оконный Qt-клиент остаётся обычным приложением Windows и подключается к контейнеру по адресу `localhost:33333`.

## Состав

- `Dockerfile` — двухэтапная сборка C++/Qt-сервера;
- `compose.yaml` — запуск сервера, публикация порта и подключение постоянного тома;
- `.dockerignore` — исключение результатов сборки, клиента, тестов и документации из контекста Docker.

На первом этапе контейнера устанавливаются компилятор, `qmake6` и заголовочные файлы Qt 6, после чего сервер компилируется. В итоговый образ попадают только исполняемый файл и библиотеки Qt, необходимые для его запуска.

## Запуск

Открыть PowerShell в корне проекта и выполнить:

```powershell
docker compose up --build -d
```

Проверить состояние:

```powershell
docker compose ps
```

После прохождения проверки состояния контейнер должен отображаться как `healthy`. Журнал сервера:

```powershell
docker compose logs -f server
```

Для выхода из просмотра журнала нажать `Ctrl+C` — контейнер продолжит работать.

## Подключение клиента

В оконном клиенте указать:

- хост: `localhost`;
- порт: `33333`.

После подключения доступны те же команды и задания, что и при локальном запуске сервера.

## Остановка и повторный запуск

Остановить контейнер:

```powershell
docker compose down
```

Повторно запустить без пересборки:

```powershell
docker compose up -d
```

## Хранение базы данных

SQLite-файл `server.db` создаётся в каталоге `/data` внутри контейнера. Каталог подключён к именованному тому `stalgolm-data`, поэтому пользователи и статистика сохраняются после `docker compose down` и повторного запуска.

Удалить контейнер вместе с сохранённой базой можно командой:

```powershell
docker compose down -v
```

Команда с параметром `-v` необратимо удаляет Docker-том и должна использоваться только тогда, когда данные больше не нужны.

## Что можно показать при защите

1. Выполнить `docker compose up --build -d`.
2. Показать контейнер `stalgolm-server` со статусом `healthy` в Docker Desktop или через `docker compose ps`.
3. Запустить оконный клиент и подключиться к `localhost:33333`.
4. Авторизоваться, запросить `Task3`, отправить ответ и посмотреть `mystats`.
5. Выполнить `docker compose down`, затем `docker compose up -d` и показать, что аккаунт и статистика сохранились.
