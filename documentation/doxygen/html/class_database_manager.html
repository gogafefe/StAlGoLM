Подробное описание

Синглтон для работы с базой данных SQLite.

Менеджер создаёт таблицу пользователей и четыре таблицы статистики, выполняет регистрацию и авторизацию, управляет ролями и результатами решения учебных заданий. База хранится в файле server.db текущего каталога.
