Подробное описание

Главное окно TCP-клиента StAlGoLM.

Окно подключается к серверу на порту 33333, формирует текстовые команды, завершает их байтом 0x01 и отображает ответы. Интерфейс поддерживает регистрацию, авторизацию, четыре типа заданий и личную статистику.
